# Studio Massage Limena — versione sportiva 2.0

## Aggiornamento su GitHub
1. Estrai lo ZIP.
2. Apri il repository collegato a Railway.
3. Premi **Add file → Upload files**.
4. Trascina tutti i file e le cartelle contenuti in `studio-massage-limena-v2`.
5. Accetta la sostituzione dei file e premi **Commit changes**.
6. Railway avvierà automaticamente il deploy.

Non eliminare PostgreSQL e non modificare le variabili già presenti su Railway.
