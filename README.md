# Studio Massage Limena — Versione 3

Versione ricostruita da zero, pronta per Railway.

## Contenuti

- Massaggiatore Sportivo FIGC
- Oltre 200 clienti trattati
- Esperienza con hotel 5 stelle ad Abano Terme
- Collaborazioni con società sportive di calcio
- Esperienza con ciclisti del Giro d’Italia
- Massaggio sportivo, decontratturante e rilassante
- 30 minuti €30 / 50 minuti €50
- Italiano e inglese
- Prenotazione online con PostgreSQL
- Area amministrativa protetta su `/admin`
- Layout responsive per desktop e smartphone

## Pubblicazione

1. Estrai lo ZIP.
2. Apri il repository GitHub collegato a Railway.
3. Carica il contenuto interno della cartella `studio-massage-limena-v3-final`.
4. Sostituisci i file esistenti e fai `Commit changes`.
5. Attendi che Railway mostri `Deployment successful`.
6. Apri il sito con una finestra anonima oppure usa `Ctrl + Shift + R`.

Non modificare o eliminare le variabili Railway esistenti:

- `DATABASE_URL`
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `NODE_ENV`
